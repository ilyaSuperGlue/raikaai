Kontribusi

Cara Berbagi Karakter

Tidak ada server, akun, atau formulir unggah. Cukup tiga langkah lewat Git.

1. Ekspor dari aplikasi

Di RaikaAI buka Characters, pilih persona, lalu ekspor sebagai JSON. Atau tulis berkas JSON baru mengikuti format di bawah.

2. Taruh di folder characters/

Simpan sebagai web/characters/nama-karakter.json dan daftarkan nama berkasnya di web/characters/index.json.

3. Kirim Pull Request

Buka PR ke repo ini. Review berarti kurasi: karakter lolos tampil di galeri setelah PR digabung.

Spesifikasi

Format JSON

Satu berkas per karakter. Field berlabel hub hanya dipakai galeri dan diabaikan aplikasi saat impor.

coder.json 
{
  "schemaVersion": 1,
  "id": "coder",
  "name": "Coder",
  "iconType": "coder",
  "description": "...",
  "greeting": "...",
  "systemPrompt": "...",
  "avatarUri": "",
  "temperature": 0.1,
  "topK": 20,
  "personality": "...",
  "scenario": "...",
  "exampleDialogues": "...",
  "author": "Nama Kamu",
  "lang": "en",
  "tags": ["code"]
}

Aturan Berkas

  • schemaVersion wajib diisi 1.
  • id unik, huruf kecil, tanpa spasi (penasihat-keuangan).
  • iconType salah satu dari: general, coder, writer, translator, reasoning, speed, shell, assistant, custom.
  • avatarUri harus kosong — avatar lokal HP tidak ikut terbagi.
  • temperature 0–2 atau null; topK bilangan positif atau null.
  • author, lang, tags hanya untuk galeri, aman diimpor aplikasi.
