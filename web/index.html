Tidak ada karakter yang cocok

Coba kata kunci atau tag lain — atau unggah JSON-mu sendiri lewat tombol di atas.

Tips: berkas .json juga bisa langsung diseret ke halaman ini.

Template JSON

Mulai dari template, salin atau unduh, lalu isi sesuai karaktermu. Semua template valid untuk diimpor aplikasi.

Panduan

Dari berkas JSON sampai karakter aktif di aplikasi.

Cara pakai hub ini

  1. Unggah — klik Upload JSON, seret berkas ke halaman, atau klik Tempel lalu tempel isi JSON.
  2. Pratinjau — klik kartu untuk melihat sapaan, system prompt, skenario, dan parameter sebelum dipakai.
  3. Ikon (opsional) — klik avatar di detail untuk mengunggah gambar sendiri atau mengunduh ikon sebagai PNG.
  4. Ambil JSON-nya — Salin JSON untuk tempel manual, atau Unduh JSON untuk berkas siap impor.
  5. Impor ke aplikasi — di RaikaAI buka Characters > Import JSON, pilih berkasnya, selesai.

Aturan berkas

  • schemaVersion wajib 1.
  • name dan systemPrompt wajib diisi.
  • id unik, huruf kecil, tanpa spasi.
  • iconType: general, coder, writer, translator, reasoning, speed, shell, assistant, custom.
  • avatarUri harus kosong untuk berkas yang dibagikan.
  • temperature 0–2 atau null; topK positif atau null.
  • author, lang, tags hanya dipakai galeri, diabaikan aplikasi.

Kirim ke galeri

  1. Simpan JSON sebagai web/characters/nama-karakter.json.
  2. Daftarkan nama berkasnya di web/characters/index.json.
  3. Buka Pull Request — karakter tampil setelah PR digabung.
